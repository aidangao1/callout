Account

The port fills in from your choices (TWS paper 7497 · TWS live 7496 · Gateway paper 4002 · Gateway live 4001). Only change it if you changed it in TWS.

Protect your account in TWS
  1. Keep Allow connections from localhost only ticked in API › Settings, and don't add other trusted IPs. With the API on, any program on this computer can place orders through TWS.
  2. Set a size limit for futures in Presets › Futures › Precautionary Settings, for example 2 contracts. TWS then stops oversized orders even if Callout had a bug.
  3. Set TWS's daily restart in Lock and Exit to a time outside your trading hours. Callout reconnects after it.

Step 1 of 4

Connect to
Trader Workstation

Callout sends your orders through TWS, so it needs to be open with its API turned on.

  1. 01Open TWS and log in with Paper selected.
  2. 02Click the gear icon, then API › Settings.
  3. 03Tick Enable ActiveX and Socket Clients.
  4. 04Untick Read-Only API.
  5. 05Check the port says 7497, and keep Allow connections from localhost only ticked. Click OK.
